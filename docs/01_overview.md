# 01. 개요 — 체크온과 AI 서비스의 역할

## 제품 한 줄

**체크온(Check-On)** — **수능 대비 국어 학원 개인 강사(고등)**를 위한, 감지 → 우선순위 → 소통 분석 레이어. (7/15: 타겟을 수능 국어로 협소화 — 중등·내신은 고도화 단계에서.) 강사가 놓치기 쉬운 학생의 위험신호를 데이터로 잡아내고, 학부모 소통을 근거 있는 초안으로 돕는다. B2C 구독(월 요금제), 테넌트 = 강사 개인.

## North Star

**주간: 경보 → 개입 완료 건수.** 경보를 많이 울리는 게 아니라, 강사가 실제로 개입을 완료하게 만드는 것.

## AI 서비스가 하는 것 / 안 하는 것

| 한다 | 안 한다 |
| --- | --- |
| 위험신호 감지 (규칙 R1~R6 — 결정론) | 학생·학부모 데이터 원본 보관 (백엔드 MySQL 소유) |
| 상담 초안·리포트 해설 생성 + 핑퐁 다듬기 | **발송·승인·확정** (전부 백엔드 HITL) |
| 엑셀 이전 매핑 추론 (적용은 결정론) | 실명·연락처 수신 (alias only) |
| 약점 기반 문제 생성·검증 결과 제안 | 문제 승인·학생 노출·채점 확정 (백엔드 HITL) |
| 문의 분류·태깅·라벨 제안 (전부 '제안' — 강사 확정 전 미사용) | 자동 응답·차단 (분류는 정렬·표시에만) |
| 사용량 미터링 | 쿼터 차단 (백엔드 Billing 소유) |

## 구성 요소 (파이프라인 v2)

- **결정론 1:** detection — LLM 0회, 야간 배치
- **워커 3 (독립 LangGraph state):** counsel_pack(상담팩 일괄, 체크포인트 중단·재개) · mapping_probe(모호한 엑셀 조사 ReAct, 루프 ≤5) · problem_generation(문제 생성·검증·수정)
- **슈퍼바이저 1 (결정론 디스패처):** 영속 Job lease·고정 operation 라우팅·실행 phase만 관리하며 LLM과 중앙 LangGraph state는 사용하지 않음
- **보조 AI 4:** ⓐ 브리핑 문장화(왜곡 게이트+템플릿 폴백) · ⓑ 문의 분류 · ⓒ 태깅 제안(수능 enum·캐시) · ⓓ 라벨 제안(인용 실존 게이트)

## 용어 최소 사전

| 용어 | 뜻 |
| --- | --- |
| alias | 실명 대신 쓰는 식별자(`st_8f2a`). 실명↔alias 매핑은 백엔드 vault만 보유 |
| evidence | 산출물의 근거 — MySQL 원본 레코드의 논리 참조(record_id). 없으면 산출물 자체가 불가 |
| 게이트 | 생성물 검증 체인: Consent → DataSufficiency → (생성) → Evidence → SourceGrounding → ToneSafety |
| 게이트 거부 = 정상 | `rejected_insufficient`·`template_only`는 200 + status — 제품이 약속대로 동작한 것 |
| label_snapshot | 초안 생성 시점의 학부모 라벨 4축 동결본 — 생성 중 라벨이 바뀌어도 초안은 일관 |
| 핑퐁 (refine) | 초안을 채팅 지시로 반복 다듬기 — 1턴 = 상담 초안 할당 1 소모, 매 턴 게이트 재통과 |
| 섀도 모드 | 파일럿 첫 2주 — 감지는 돌지만 경보 미발송 (임계 보정 기간) |
| 노출 3층 | 학생 = 비교 일절 비노출 / 학부모 = 전국 백분위만 / 반 평균·석차 = 강사 내부 전용 |
| 15일 규칙 | 15일 이후 등원생은 그 달 월별 리포트 생략 (대상 선정은 백엔드 소유) |
| 관찰 중 | 데이터 2주 미만 학생 — 어떤 규칙도 평가하지 않음 |
