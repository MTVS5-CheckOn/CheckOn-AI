# 12. 학부모 새 라벨 발굴 (테넌트 내 군집) — 설계 메모

작성 A(박진희) · 2026-07-31 · 상태: **Phase 2 백로그(99 D ㉜)** — §6 착수 조건 충족 전 **코드 착수 금지**(CLAUDE.md "문서에 없는 설계는 코드에 넣지 않는다"의 역방향: 문서만 먼저 둔다).

> **한 줄:** 기존 4축 라벨(소통 성향·관심사·민감도·빈도)로 분류되지 않는 상담 패턴이 반복되면, **그 강사의 데이터 안에서** 군집을 발견해 AI가 **행동 서술형 이름까지 제안**하고, 강사가 라벨 검토함에서 **수락·편집·무시**한다. 학원마다 학부모 특성이 다르다는 관찰이 출발점이다.

## 1. 형태 — 상담 초안과 동형의 패턴

LLM 자유 산출 → 결정론 게이트 → HITL 확정. 이미 검증된 구조를 재사용한다. 단 **라벨은 초안과 달리 영속 설정값**이다 — 사람에게 붙어 이후 모든 초안·리포트 톤을 조용히 바꾼다(파급 크고 비가시). 그래서 게이트를 한 겹 더 둔다(§3 ③).

```
상담 텍스트(마스킹 통과분) → 임베딩 → 테넌트 내 군집
  → 미분류 군집 후보 → LLM: 공통점 서술 + 이름 제안 (게이트 ①~③)
  → 라벨 검토함 노출 → 강사 수락/편집/무시 (게이트 ④) → 확정 시에만 적용
```

## 2. 불변식 정합

- **불변식 1** — LLM은 군집 서술·이름을 **제안까지만**. 확정은 강사(HITL). 군집 계산 자체는 결정론(임베딩·클러스터링 파라미터는 버전 관리 — 불변식 8).
- **불변식 2** — 근거 없는 제안 없음. 제안마다 근거 상담 참조(record_id 논리 참조)가 동반되며, 근거가 비면 생성 단계에서 드롭.
- **불변식 3** — 군집 입력은 마스킹 통과분만. **테넌트(강사) 경계 밖 대조·비교·군집 없음** — 학원 간 유사도는 계산 자체가 존재하지 않는다(Import `source_fingerprint`의 tenant 스코프와 같은 원칙).
- **라벨 정책** — 평가성 라벨 차단은 **이름의 출처와 무관**하게 적용된다. AI 제안이든 강사 편집이든 같은 필터를 지난다(불변식 5와 같은 결 — 강사 지시가 게이트를 이기지 못한다).

## 3. 게이트 4종

| # | 게이트 | 판정 | 비고 |
| --- | --- | --- | --- |
| ① | 패턴 실재 검증 | 추출된 공통 패턴이 근거 상담 원문(마스킹 통과분)에 실재하는가 — 결정론 대조 | grounding.py 선례(record_id 실존 대조) |

## 4. 저장소 — pgvector 재론 (99 D ㉜)

- **pgvector 채택 제안.** 7/25 "도입 안 함" 결정은 당시(evidence 계층) 필요 부재였고, 텍스트 유사도 군집이라는 새 필요가 생겼다. 기존 AI PG의 확장이라 **파기(30일)·동의 철회 파기·백업·CI services를 전부 재사용**한다.
- **Neo4j 부결 사유:** 새 서비스 = 상담 파생 데이터를 담는 **개인정보 저장소가 하나 더** 생기고, 수명주기 규칙(마스킹·파기·철회)을 이중 구현해야 한다. 이 문제는 그래프 관계 질의가 아니라 텍스트 유사도 문제라 임베딩+군집이 자연 도구다. 그래프 질의 필요성(예: 학부모—주제—반응 관계 탐색)이 실증되면 재검토한다.
- **수명주기 동승:** 원 상담이 파기되면 파생 임베딩·군집 결과도 함께 파기된다.

## 5. 콜드 스타트 · 데모

- v1 준비물은 하나 — 기존 4축 제안이 **"기타/해당 없음"으로 빠지는 비율을 섀도 지표로 수집**한다(코드 최소·판정 무영향). 이 수치가 "4축이 X%를 못 담는다"는 착수 근거가 된다(R7 섀도 선례).
- 시연은 시드 합성 상담 이력로 가능(실사용자 없는 포트폴리오 — 데모 시나리오는 착수 시 backend_sim 선례로).

## 6. 착수 조건 (순서 고정 — 셋 다 충족 전 코드 금지)

1. **상담 축 데모 완성** — counsel 라우터(B-4)·실 LLM 스모크가 끝나 기본 축이 선 다음.
2. **동의 문구 확인(백엔드·승우)** — 현행 동의의 AI 처리 범위("리포트·답변 초안 작성 보조")에 상담 텍스트의 2차 활용(성향 분석)이 포함되는지. 미포함이면 동의 문구 개정이 선행.
3. **pgvector 재론 확정** — 99 D ㉜, 스택 결정이므로 B와 함께(03 §1b 신규 의존 사유 포함).
