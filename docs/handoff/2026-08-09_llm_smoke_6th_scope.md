## 🔴 몇 콜인가 — 코드에서 센 수

| 시나리오 | 콜의 출처 | 수 |
| --- | --- | --- |
| **S1** 브리핑 | 데모 신호 × `_REPEATS`(**3** · 코드 상수) | 5차 실측 **7신호 × 3 = 21** |
| **S2** counsel 초안 | `_s2_cases()` **4건** × (plan 1 + write 1~3 게이트 재생성) | 5차 실측분에 포함 |
| **S3** refine 공격 | 생성 케이스 + `_POST_GEN_ATTACKS`(**2**) | 같음 |
| **S5** 재현성 | `_run_s2(repeat_first=True)` **×2**(첫 케이스만) | 같음 |
| **합계** | `s4.records_captured`가 세는 값 | 🔴 **33콜**(5차 실측 · 토큰 20,131) |

🔴 **「33콜」의 근거는 「5차 실측 + 구조 무변경」이다.** 5차 커밋(`8839a9f`) 이후 러너에서
`_REPEATS`·`_s2_cases`·`_POST_GEN_ATTACKS`·`repeat_first`·반복 `range(`를 건드린 diff가
**0줄**이다(전수). 그리고 5차 이후 counsel 산출 경로 변경 둘은 **콜 수에 안 닿는다**:

- **PR-ι** `_mask_plan_output` — **응답을 받은 뒤** 문자열을 변형한다(호출 전이 아니다)
- **PR-λ** `pack_result_id`·`created_at` — **저장 축**이다

⚠ **편차 원인은 게이트 재생성 하나**다 — 5차 리포트 자신이 *"+1콜 — S5 반복 분포 차"* 로
적었다(4차 32 → 5차 33). ⇒ **예상 33콜 · 상한 대략 36콜**로 보시면 된다.

## 볼 값과 판정 기준

| 값 | 기준 |
| --- | --- |
| 🔴 **`pii.emphasis_scanned`** | **> 0 ⇒ 배선 OK** · **== 0 ⇒ 배선이 안 닿았다**(`_run_s2`가 강조점을 행에 안 담았거나 plan이 전량 드롭) |
| `pii.masked` | ⚠ **0이 정상이다** — 강조점은 **이미 마스킹본**이라(PR-ι가 포착 시점에 가린다) 여기서 새 `findings`가 날 이유가 없다 |
| 🔴 `pii.token_residue` | **0이어야 한다.** 0이 아니면 마스킹 토큰이 산출물에 남았다 — 두 번 가려졌거나 모델이 토큰을 따라 썼다 |
| 🔴 `pii.uncertain` + `uncertain_detail` | 조각을 **사람이 본다.** `uncertain`은 *"실명이 나갔다"* 가 아니라 *"불확실해서 안 보냈다"* 이고 **오탐인지 진탐인지는 조각을 봐야** 안다(99 ㊪) |

⚠ **`findings` 0을 「안전하다」로 읽지 마라**(99 #28) — `redact()`는 **문맥 신호(호칭·조사)가
있어야** 인명을 확정하고 `"김민준"` 단독은 안 잡는다. **커버리지는 fail-closed가 아니다.**

5차 이후 PR이 여덟(θ·ι·κ·λ·μ·ν·ξ·ο) 들어갔다. 그중 **counsel 산출에 닿는 것 둘**:

| **PR-ι**(#169) | plan 산출을 **포착 시점에 마스킹**(`_mask_plan_output`) | 🔴 **강조점 문면이 바뀐다** — `s2.rows[].emphasis`에 `⟪이름N⟫`이 섞여도 **정상**이다. ⚠ 그 값이 다음 프롬프트로 되돌아가므로 **초안 본문에 마스킹 토큰이 새면**(`token_residue`) 그게 회귀다 |
| **PR-λ**(#171) | 팩 결과 `id`=`uuid5(job_id)` · `created_at`=`job.started_at or queued_at` | 원장·팩 레코드가 제대로 앉는가. ⚠ **시각이 실행 시각과 다른 것이 정상**이다(잡 시작 시각이다) |

**그 밖 여섯은 산출에 안 닿는다**: θ(저장소 경계·관측) · κ(팩 PG) · μ(관측 둘) · ν(날짜·인용
정합) · ξ(probe 수렴) · ο(이 게이트). ⚠ **닿지 않는다는 것도 적는다** — 회귀를 어디서 안 볼지가
정해져야 *"emphasis만 보려다 회귀를 놓쳤다"* 가 안 된다.

🔴 **회귀가 나면 그것이 이 회차의 산출이다** — `emphasis_scanned`보다 먼저 보고한다.
