## 1. 결론

현재 M2는 **수능형 5지선다 문항의 안전성 기반**에는 맞지만, **수능 전 영역
시험지 생성기**는 아니다.

- 맞는 부분: 5지선다·단일 정답·오답 사유·근거·blind 교차 풀이·재생성 상한.
- 현재 실행 범위: `language`·지문 없음인 T1만. 평가원형으로는 「언어와 매체」
  언어 문항 일부에 대응한다.
- 핵심 간극: 공유 지문 문항군·복합 자료·2/3점 배점·공통/선택 조립·학생에게
  보이는 자료를 verifier에 전달하는 계약.

M2 T1의 범위를 억지로 넓히지 않는다. 기존 수직 슬라이스는 유지하고, 수능형
확장은 별도 계약과 단계별 게이트를 통과한 뒤 연다.

## 2. 평가원 문제지에서 확인한 구조

2027학년도 6월 모의평가 국어는 응시자 기준 공통 34문항과 선택 11문항으로
구성된다. 문제지에는 두 선택과목이 모두 실려 있다.

| 구분 | 문항 | 주요 형식 |
| --- | ---: | --- |
| 공통 독서 | 1~17 | 단일·복합 지문, 문단 관계, 개념 적용, `<보기>` |
| 공통 문학 | 18~34 | 작품 묶음, (가)/(나), 표현·서사·외적 준거 적용 |
| 화법과 작문 | 35~45 | 발표·대화·인터뷰·초고·자료 활용 |
| 언어와 매체 | 35~45 | 언어 자료·표·예문, 방송·블로그·화상 회의·이미지 |

형식 불변식:

1. 전 문항 5지선다이며 정답은 하나다.
2. 2점·3점 문항이 함께 있고 응시 과목 조합의 총점은 100점이다.
3. 대부분 문항은 독립 문두가 아니라 공유 지문·자료 묶음에 속한다.
4. `<보기>`·㉠~㉣·ⓐ~ⓔ·(가)/(나)·표·그림이 풀이 정보다.
5. 선택과목은 한 영역만으로 구성되지 않는다. 화법+작문, 언어+매체를 조합한다.

이 구조는 원문 내용과 분리 가능한 시험 포맷 사실이다. 저장소 골든에는 평가원
문구를 옮기지 않고 같은 구조를 가진 합성 자료만 사용한다.

## 3. 현재 구현과의 대조

| 항목 | 현재 상태 | 판정 |
| --- | --- | --- |
| `ItemFormat.MCQ` | 5개 선지·1개 정답 강제 | 적합 |
| `Choice.why_wrong` | 모든 오답 사유 필수 | 적합 |
| `EvidenceAnchor` | 최소 1개 근거 필수 | 적합 |
| `AreaTag` | 독서·문학·화법·작문·언어·매체 6영역 | 어휘는 적합 |
| `TypeTag` | `fact`·`infer`·`critic`·`concept` 4종 | 표현력 부족 — 상세 근거·제안은 [`09`](09_integration_proposals.md) §2-13 |
| `ProblemGenerationWorkflow` | `AreaTag.LANGUAGE`·`passage=None`만 허용 | T1 파일럿 |
| `ProblemRequest.area_tag` | 세트 전체 단일 영역 | 선택과목 조립 불가 |
| `GeneratedItem` | `stem`·`choices` 중심 | 복합 자료 구조 없음 |
| `BlindCrossSolver` | 문두·선지만 전달 | 지문형 확장 전 보완 필요 |
| `curriculum_graph.yaml` | 현대 국어 문법 중심 | 국어사 포함 교과 검수 필요 |
| `difficulty_est` | T1 결정론 추정 | 2/3점 배점과 별개 |
| `golden/problems` | 실패 분기·구조 중심 | 평가원형 포맷 코퍼스 보강 필요 |

`stem`은 여러 줄·특수 기호·합성 표를 문자열로 보존할 수 있으므로 T1의 단일 자료
문항은 기존 계약 안에서 시험할 수 있다. 하지만 여러 문항이 한 자료를 공유하거나
이미지를 포함하는 경우를 문자열 복제로 해결하지 않는다.

## 4. B 단독으로 즉시 이행하는 항목

### FMT-B1. 저작권 안전 합성 포맷 골든

`golden/problems/suneung_format/`에 다음 구조를 합성 데이터로 고정한다.

- 설명 자료 + 문항
- ㉠~㉣ 예문 묶음
- 텍스트 표
- 옛한글을 포함한 문자열 왕복
- ㄱ·ㄴ 조합형 선지
- 공유 자료 문항군의 **현 계약 미지원** 기록

전 케이스는 `expert_review_pending`이며 교육 내용 정답으로 사용하지 않는다.

### FMT-B2. 기존 T1 계약의 표현력 회귀

`GeneratedItem`이 여러 줄 자료·원문 기호·조합형 선지를 JSON 왕복해도 손실되지
않는지 계약 테스트로 고정한다. 프로덕션 필드는 추가하지 않는다.

### FMT-B3. 평가 보고의 정직성

골든 보고서에 수능형 포맷 feature와 `design_gap` 케이스를 분리한다.
구조 파일이 존재한다는 이유로 실모델·교과 품질 검증이 끝났다고 보고하지 않는다.

| 안건 | 필요한 결정 | 관련 오너 | 승인 전 처리 |

| FMT-2 공유 문항군 | 자료 1개와 문항 N개의 키·순서·복제 금지 — **묶음 키는 `passage_ref` 계약을 그대로 따른다**(아래) | B+A(DB)+BE | 설계만 |

| FMT-8 T2·T3 | 트랙 정의·자료 요건은 [`05`](05_problem_generation.md) §1 정본 참조 | B+기획+권리 담당 | 트랙 미개방 |
| FMT-9 화작·매체 | 대화·매체 자료 생성·검증 규격 | B+제품+FE | 트랙 미개방 |
| FMT-10 조판 | 표·그림·페이지 나눔·문항 번호 | B(P2)+FE/디자인 | `print_layout.py` 미착수 |
| FMT-11 기출 유사도 | [`05`](05_problem_generation.md) §8.3·[`09`](09_integration_proposals.md) §3 C-15 참조 | B+기획+권리 담당 | C-15 대기 · 코퍼스 미반입 |

**FMT-2의 묶음 키 — 새로 만들지 않는다 `[2026-08-04]`.** `learning_events[].passage_ref`가
[`05_request_json.md`](../05_request_json.md) `[A 확정 통보 2026-08-03 · 승우 합의]`로
확정됐다. **의미가 FMT-2가 필요로 하는 것과 같다** — "같은 지문·도표·〈보기〉 자료를
공유하는 문항들이 같은 값을 갖고 재출제 시에도 유지되며, 비지문 자료도 포함하는 불투명
키"다. M2 산출 문항의 자료 묶음 키를 이 규약에 맞추면 세 가지가 따라온다.

- **BE에 추가 요청이 없다.** 기존 교재·기출은 백엔드가 채우고, M2 문항은 B가 같은 형식으로
  발급한다. 두 출처의 문항이 같은 통계 축에 얹힌다.
- **기대치 층에 그대로 편입된다** — `PASSAGE_TYPE_STAT`(`db/models.py`)이 지문×유형으로
  누적하므로, M2 문항도 발행 후 응답이 쌓이면 같은 방식으로 기대 정답률을 갖는다.
  [`09`](09_integration_proposals.md) §3 W12·W13의 재료다.
- **별도 키를 만들면 축이 갈라진다.** FMT-2 전용 키를 신설하면 같은 학생의 학습 로그가 두
  체계로 쪼개져 기대치 산출이 성립하지 않는다.

`contracts/taxonomy.py`·`db/models.py`·공개 API·공용 evidence를 변경해야 하는
구현은 해당 승인 없이 시작하지 않는다.

## 6. 제안하는 확장 순서

1. T1 합성 포맷 골든과 기존 계약 왕복을 고정한다.
2. FMT-1~5의 자료·문항군·배점 공개 계약을 합의한다.
3. `StimulusBundle`을 도입하고 verifier가 학생 가시 자료를 받도록 한다.
4. 현대 문법 T1을 실제 기준 자료와 교사 검수로 닫는다.
5. 국어사 T1을 별도 노드·골든으로 연다.
6. T2 독서 → T3 문학 → 화법·작문 → 매체 순으로 확장한다.
7. 마지막에 시험 구성표와 P2 조판을 연결한다.
