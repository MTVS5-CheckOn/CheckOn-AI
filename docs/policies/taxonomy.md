# [체크온] 수능 영역·문항 형식 태그 어휘집 v0 — Open-11 합의 자료 `[A+B]`

> **지위:** member-A 단독 초안. B-3 합의 미팅에서 이 문서로 enum을 확정하고, 확정본이 `contracts/` 공용 어휘가 된다. 확정 전까지 모든 코드·문서의 area enum은 "잠정".
> **소비처가 4곳이라 동시 개정 필수:** 감지 R6(오답 유형 편중) · 약점 지도 · 태깅 제안ⓒ · B의 출제/진단 그래프 — 하나라도 다른 어휘로 출발하면 통합 시 재작업.

---

## 1. `area_tag` — 수능 국어 6영역 (기존 3갈래 대체)

| 값 | 영역 | 정의 | 수능 체제 |
| --- | --- | --- | --- |
| `reading` | 독서 | 비문학 지문 독해(인문·사회·과학·기술·예술·융합) | 공통 |
| `literature` | 문학 | 현대시·현대소설·고전시가·고전산문·극/수필 | 공통 |
| `speech` | 화법 | 발표·토론·협상 등 담화 상황 | 선택 「화법과 작문」 |
| `writing` | 작문 | 글쓰기 계획·초고 수정·자료 활용 | 선택 「화법과 작문」 |
| `language` | 언어(문법) | 음운·단어·문장·담화·국어사 | 선택 「언어와 매체」 |
| `media` | 매체 | 매체 자료의 수용·생산(인터넷·방송 등) | 선택 「언어와 매체」 |

**메타 필드 `subject_track`:** `common`(공통: 독서·문학) | `elective`(선택과목). 영역값에서 유도 가능하지만, **고1·중등처럼 선택 체제가 아닌 학생**의 데이터를 구분하기 위해 별도 필드로 유지한다.

**하위 분류(2차 태그, 선택):** `reading.humanities` `literature.classic_poetry` 식 점 표기 확장을 예약 — v0에서는 6영역만 필수, 하위는 B의 약점 지도 세분화 요구에 따라 v1에서 논의.

### 1.1 기존 3갈래 → 신규 매핑 (마이그레이션)

| 기존 | 신규 | 비고 |
| --- | --- | --- |
| `grammar` | `language` | 1:1 |
| `reading` | `reading` | 값 동일 — 의미 협소화(비문학 한정) 주의 |
| `literature` | `literature` | 1:1 |
| (없었음) | `speech` `writing` `media` | 기존 데이터에는 미태깅 — 태깅 제안ⓒ가 소급 채움 |

### 1.2 중학생 처리

중등 내신은 수능 체제가 아니므로 6영역의 **상위 매핑**으로 태깅한다(문법→`language`, 비문학→`reading`, 문학→`literature`, 듣기·말하기→`speech`, 쓰기→`writing`). `subject_track`은 항상 `common`. 리포트·약점 지도는 동일 어휘로 그려지므로 별도 enum 불필요.

## 2. 경계 판정 사례집 (태깅 제안ⓒ·강사 확정 UI의 기준)

| # | 사례 | 판정 | 근거 |
| --- | --- | --- | --- |
| 1 | 독서 지문 안에 문법 개념 설명(예: 훈민정음 제자 원리 지문) | `reading` | **출제 형식 기준** — 지문 독해력을 측정하면 독서. 문법 지식 자체를 물으면(밑줄 친 음운 현상 등) `language` |
| 2 | (가) 현대시 + (나) 평론 복합 지문 | `literature` | 문학 작품 감상이 중심축. 평론 독해 문항이 별도로 있으면 문항 단위로 분리 태깅 |
| 3 | 화법+작문 통합형(토론 후 글쓰기) | 문항 단위 분리 | 세트가 아닌 **문항 단위 태깅 원칙** — 담화 이해 문항=`speech`, 고쳐쓰기 문항=`writing` |
| 4 | 매체 지문 속 언어(문법) 문항 | `language` | 측정 대상 기준. 매체 자료 수용·생산을 물으면 `media` |
| 5 | 고전시가 현대어 풀이 문항 | `literature` | 국어사 지식을 직접 물을 때만 `language` |
| 6 | 융합 지문(과학+예술) | `reading` | 하위 분류 도입 전까지 융합도 `reading` 단일 |
| 7 | 어휘(한자어·속담) 문항 | 지문 소속 영역 따름 | 독서 지문의 어휘 문항=`reading`. 독립 어휘 시험지는 `language` |

**원칙 요약:** ① 세트가 아닌 **문항 단위**로 태깅 ② 지문 소재가 아니라 **측정 대상(무엇을 묻나)** 기준 ③ 애매하면 태깅 제안ⓒ가 `confidence`를 낮춰 제시하고 강사 확정에 맡긴다(자동 확정 금지 — 기존 규약 그대로).

## 3. `type_tag` — 인지 유형 (area와 직교, 변경 없음)

`fact`(사실 확인) | `infer`(추론) | `critic`(비판·평가) | `concept`(개념·지식). 모든 area와 조합 가능 — 예: `literature × infer`(화자 정서 추론), `language × concept`(음운 규칙 지식).

## 4. `item_format` — 문항 형식 (신규 축)

| 값 | 형식 | 채점 | AI 관여 |
| --- | --- | --- | --- |
| `mcq` | 객관식(5지선다) | 자동(정오) | 없음 — 정오만 피처로 |
| `short` | 단답형 | 자동(문자열 매칭) + 유사 답안은 강사 확인 | 유사 답안 후보 제시 `[제안]` |
| `essay` | 서술형 | **루브릭 1차 제안 → 강사 확정** | LLM이 루브릭 기준별 채점 초안 + 근거 문장 인용. **확정 전 점수는 피처·리포트에 미반영** |

**서술형 채점 분담(B-4 안건):** 루브릭 생성·채점 초안 = **B**(출제·진단 소유). 확정된 채점 결과를 감지 피처(R1·R6)·리포트 문장으로 소비 = **A**. 경계는 "확정 이벤트"— 백엔드가 강사 확정 시점에 learning_event로 발행.

**R6 집계 축 (문서 #3 threshold 시트와 연동):** v0 제안 = `area_tag × type_tag` 기본 + `item_format`은 **분리 리포팅만**(편중 판정 축에는 미포함 — 셀이 6×4×3=72개로 쪼개지면 학생당 표본 부족). 파일럿 데이터로 재평가.

## 5. 소비처 매핑표

| 소비처 | 소유 | 쓰는 필드 | 용도 |
| --- | --- | --- | --- |
| 감지 R6 | A | area×type 정답률 | 오답 유형 편중 신호 |
| 약점 지도 | B | area(×하위 분류 예정) | 진단 그래프·출제 입력 |
| 태깅 제안ⓒ | A | 전 필드 | 과제명→태그 추론 |
| 문제 생성 | B | area·type·item_format | 영역·형식 지정 출제 |
| 리포트 차트 ① | A | area 정답률 | 영역별 약점 현황 |
| 표준 스키마(F1·Import) | A+백엔드 | 전 필드 | 업로드 템플릿 컬럼 |

## 6. 합의 절차 (B-3 미팅)

1. 6영역 enum + subject_track + item_format 승인 여부 — 반례: B가 하위 분류를 v0부터 원하면 점 표기 즉시 도입
2. §2 경계 사례 7건 판정 합의(태깅 골든셋의 시드가 됨)
3. §4 서술형 분담(B-4)과 R6 집계 축 승인
4. 확정 → `contracts/`에 enum 반영 + 계약 v1.0의 Open-11 체크 + 표준 스키마 정의서(#1)에 컬럼 확정
